# Energasio – Website-Vorschau

Statische Vorschau der Energasio-Website zur Abstimmung.

**Kein Live-Auftritt.** Kontaktdaten, Impressum und Datenschutzerklärung sind Platzhalter
und rechtlich nicht geprüft. Die Seiten sind auf `noindex` gesetzt und über `robots.txt`
für Suchmaschinen gesperrt.

Formulare (Kontakt, Portfolio-Analyse, Newsletter) prüfen nur im Browser und versenden
nichts.
